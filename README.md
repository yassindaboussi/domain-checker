## ✨ Features

- 🚀 **Real-time checking** - Instant domain availability via ICANN RDAP
- 🌍 **All TLDs supported** - Works with gTLDs & ccTLDs
- 🎨 **Beautiful UI** - Clean, modern, and responsive design
- 📱 **Mobile-friendly** - Works perfectly on all devices
- ⚡ **Keyboard shortcuts** - Press Enter to check
- 🎯 **Error handling** - Graceful handling of rate limits & network issues
